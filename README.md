# Heures Pro V50

Chaque heure travaillée est comptée une seule fois au taux normal. Les heures de nuit reçoivent uniquement la majoration nuit, et les heures supplémentaires leur majoration (+25 % / +50 % du taux, réglable).

Les primes équipe, habillage et le panier ne sont comptés que les jours travaillés. Les primes & indemnités saisies dans les réglages sont comptées chaque mois travaillé. Les estimations du jour et de la semaine incluent l'IFM et les congés payés versés, comme le calcul mensuel. Un poste de nuit qui passe minuit reste rattaché à son jour de début.

Le taux horaire normal est modifiable. Les montants liés au taux évoluent proportionnellement : 1,84 €/h, 14,50 €/jour, 1,93 €/jour, 3,50 €/jour, 0,47 €/jour, majoration nuit 6,89 €/h et 0,91 €/h. Le panier reste fixe à 7,50 € net/jour.
